Travel distance calculator

Type where each journey started and ended. One-way distances only. For a return trip, don't double it.

How is this calculated?

Air and ferry use straight-line distance. Vehicle uses the driving route. Rail is estimated from the driving route, because no free rail routing exists. Results are estimates for carbon footprint reporting.

Privacy: this tool doesn't store or collect anything. The place names you type are sent to OpenStreetMap and OSRM only to look up the distance.
